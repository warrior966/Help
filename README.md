# College Opportunity Fund — Demo

A responsive, single-file fundraising dashboard concept in English.

## Important
This is a **simulation only**. It does not accept payments, collect personal or financial information, or represent real donations. All donor names and amounts generated by the buttons are fictional and reset when the page is refreshed.

The concept is independently inspired by the general goal of expanding college access, including LeBron James' 2015 University of Akron scholarship commitment for eligible I PROMISE graduates. This project is not affiliated with or endorsed by LeBron James, the LeBron James Family Foundation, the University of Akron, or the I PROMISE program.

## Configure the goal
Open `index.html` and change the value of `GOAL_AMOUNT` near the bottom:

```js
const GOAL_AMOUNT = 100000;
```

The progress display updates automatically.

## Run locally
Open `index.html` in any modern browser. No build tools or dependencies are required.
